# Machine Learning-Based Tender Final Price Prediction

## Project Overview

This project focuses on predicting final tender prices using machine learning techniques and large-scale public procurement data.

The Global Public Procurement Dataset (GPPD) contains procurement records from multiple countries. Germany was selected as the focus country for this project.

## Project Objectives

- Analyze large-scale public procurement data.
- Perform data cleaning and preprocessing.
- Handle missing values.
- Apply feature engineering and feature transformations.
- Develop and compare machine learning models.
- Evaluate model performance using regression metrics.

## Machine Learning Models

- XGBoost
- Neural Networks (Keras)
- AutoGluon

Optuna was used for hyperparameter optimization of the XGBoost model.

## Methodology

1. Data loading and exploratory data analysis
2. Data cleaning and preprocessing
3. Missing value analysis and imputation
4. Feature engineering
5. Data transformation and encoding
6. Model development and training
7. Hyperparameter optimization
8. Cross-validation
9. Model evaluation and residual analysis
